Pipeline — Job Application Tracker
Elevator Pitch: A Kanban-style job application tracker that helps candidates organize their job search, track interview stages, and never miss a follow-up.
Core Features

Drag-and-drop Kanban board (Applied → Phone Screen → Interview → Offer → Rejected)
Add/edit job cards with company, role, salary, notes, and links
Email/notification reminders for follow-ups
Dashboard with stats (response rate, avg. time per stage)
Google OAuth login

Tech Stack

Frontend: React + Tailwind CSS
Backend: Node.js + Express
Database: PostgreSQL
Auth: Google OAuth (Passport.js)
Email: Resend or Nodemailer
Deployment: Vercel (frontend) + Railway (backend)

Stretch Goals

Chrome extension to save job postings from LinkedIn/Indeed
AI-generated cover letter drafts per job card
Export applications to CSV
